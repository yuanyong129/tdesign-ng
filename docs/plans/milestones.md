# 里程碑记录

发布版本号与开发里程碑是**两套编号**，不要混用：

| 用途 | 载体 | 例子 |
| --- | --- | --- |
| npm 包版本 | 三个 `package.json` 的 `version` + 同号 git tag | `0.1.0` / tag `v0.1.0` |
| 开发里程碑 | 本文件的表格 | `0.4`（广度完成） |

规则（原因见 `RELEASING.md` 的「版本与 tag」一节）：

- **git tag 只用于发布**：tag 名必须是 `v<version>`，且该 version 必须等于 `packages/ng-components/package.json` 的 `version`。`.github/workflows/release.yml` 会校验，不一致会直接中止发布。
- **里程碑不打 tag**：阶段进度记在本文件。此前打过的里程碑 tag（如 `v0.4.0-alpha`）与 npm 版本号体系混在一起，容易让人误以为 npm 上存在 `0.4.0`，已在 0.1.0 首发准备时删除，内容原样保留在下表中。
